# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

We take the security of **MdPersia** seriously. If you discover a security vulnerability, please do NOT disclose it publicly on GitHub issues.

Instead, please send an email or submit a private security advisory via GitHub:
1. Go to the [Security Advisories](https://github.com/hamid-morsali-786/MdPersia/security/advisories) tab on GitHub.
2. Click **Report a vulnerability**.
3. Provide details about the affected version, proof of concept, and potential impact.

We will acknowledge receipt within 48 hours and work with you to triage and address the issue swiftly before a public disclosure.
