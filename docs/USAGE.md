# راهنمای استفاده

## دستور کلی

```powershell
fa-md-pdf INPUT [OPTIONS]
```

`INPUT` می‌تواند یک فایل Markdown یا یک فولدر باشد.

برای اجرای رابط گرافیکی:

```powershell
mdpersia --gui
```

با دادن مسیر یک سند، همان فایل مستقیماً در تب پیش‌نمایش باز می‌شود:

```powershell
mdpersia --gui .\README.md
```

### محیط مطالعه و تنظیمات خروجی

فرمول درون خط را با `$t_{tx}=0.8\,\mathrm{ms}$` و فرمول مستقل را میان دو خط `$$` بنویسید. پیش‌نمایش و HTML از MathML بومی، آفلاین و بدون CDN استفاده می‌کنند؛ جهت فرمول همواره LTR و مستقل از متن فارسی است. کسر، توان، زیرنویس و کادر نتیجه رندر می‌شوند. escapeهای اضافی ابتدای/انتهای خط فرمول و `\_{...}` در فرمول‌های منتقل‌شده از Markdown پذیرفته می‌شوند، بدون تغییر فایل اصلی. کدهای محصور در backtick تفسیر ریاضی نمی‌شوند. برای فاصله میان مقدار و واحد، `\,` بنویسید؛ ویرگول معمولی در LaTeX همچنان ویرگول است.

نصب‌کنندهٔ محلی `math-fix`، Setup بومیِ پذیرفته‌شدهٔ beta.3 و موتور نمایش بازسازی‌شده را ترکیب می‌کند. پوستهٔ Tauri و catalog بستهٔ تبدیل همان beta.3 هستند؛ این hotfix پشتیبانی ریاضی را به پیش‌نمایش/HTML اضافه می‌کند و پشتیبانی فرمول در Word یا موتور اختیاریِ قبلاً منتشرشده را تضمین نمی‌کند. برای ساخت محلی از `scripts/build-math-hotfix.py --help` استفاده کنید؛ این دستور هیچ چیزی منتشر نمی‌کند.

صف فایل‌ها سمت راست است؛ پیش‌نمایش و کنسول در بخش میانی قرار دارند و تنظیمات خروجی در سایدبار سمت چپ هستند.

- با دکمهٔ «پنهان‌کردن تنظیمات خروجی» در نوار بالای محیط مطالعه یا کشیدن جداکننده تا لبهٔ چپ، سایدبار کاملاً جمع می‌شود و فضای بیشتری به سند می‌رسد. همین کنترل برای بازکردن دوباره هم استفاده می‌شود.
- برای بازکردن دوباره، دکمهٔ «نمایش تنظیمات خروجی» در نوار بالای محیط مطالعه را بزنید؛ کشیدن جداکننده از لبه به سمت راست هم سایدبار را باز می‌کند.
- بسته‌بودن سایدبار و آخرین عرض آن ذخیره می‌شوند. بستن سایدبار، گزینه‌های تبدیل یا اسناد باز را پاک نمی‌کند.
- سایدبار در حالت باز حداقل ۳۰۰ پیکسل عرض دارد؛ هنگام کشیدن به سمت بسته‌شدن، محتوا باریک و درهم نمی‌شود و پس از عبور از آستانه، پنل یک‌باره جمع می‌شود.
- جداکننده با کلیدهای چپ و راست هم تغییر اندازه می‌دهد؛ کلید Home یا دوبار کلیک، عرض پیش‌فرض را برمی‌گرداند.
- تم تاریک و روشن برای خطوط و برچسب‌های نمودار و رنگ‌بندی کد پالت مستقل دارند. این تنظیمات مطالعه، استایل خروجی PDF و Word را تغییر نمی‌دهند.

برای افزودن «باز کردن با MdPersia» به منوی راست‌کلیک ویندوز (فقط HKCU، بدون ادمین):

```powershell
mdpersia --register-associations
mdpersia --association-status
mdpersia --unregister-associations
```

## حالت فایل تکی

```powershell
fa-md-pdf .\docs\intro.md
```

خروجی:

```text
.\docs\intro.pdf
```

با مسیر خروجی مشخص:

```powershell
fa-md-pdf .\docs\intro.md -o .\out\intro.pdf
```

یا:

```powershell
fa-md-pdf .\docs\intro.md -o .\out
```

در حالت دوم خروجی می‌شود:

```text
.\out\intro.pdf
```

## حالت فولدر

```powershell
fa-md-pdf .\docs
```

در حالت پیش‌فرض، خروجی هر فایل کنار همان فایل ساخته می‌شود.

با فولدر خروجی:

```powershell
fa-md-pdf .\docs -o .\pdf
```

ساختار زیرپوشه‌ها حفظ می‌شود.

## حالت DOCX (Word)

```powershell
fa-md-pdf .\docs -f docx -o .\docx-output
```

نمودارهای Mermaid به‌صورت تصویر PNG با کیفیت بالا داخل سند جای می‌گیرند.

## حالت بسته‌بندی RTL در Markdown

برای افزودن خودکار `<div dir="rtl">...</div>` به بلوک‌های فارسی فایل‌های Markdown:

```powershell
fa-md-pdf .\docs --wrap-rtl
```

پیش‌فرض: کنار هر فایل، نسخه‌ای با پسوند `.rtl` ذخیره می‌شود (`file.md → file.rtl.md`). برای تغییر یا حذف پسوند از `--wrap-rtl-suffix` استفاده کنید.

## گزینه‌های مهم

### عمومی

| گزینه | توضیح |
|---|---|
| `-o, --output` | فایل خروجی برای ورودی تکی یا فولدر خروجی برای ورودی فولدر |
| `-f, --format` | `pdf` یا `docx`. پیش‌فرض: `pdf` |
| `--gui` | باز کردن رابط گرافیکی به‌جای تبدیل؛ با دادن مسیر سند، همان فایل در تب پیش‌نمایش باز می‌شود |
| `--register-associations` | افزودن «باز کردن با MdPersia» برای `.md` و `.markdown` در رجیستری کاربر (HKCU) |
| `--unregister-associations` | حذف فقط کلیدهایی که `--register-associations` ساخته است |
| `--association-status` | نمایش دستور ثبت‌شده و سالم بودن آن برای دابل‌کلیک |
| `--recursive` | تبدیل فایل‌های زیرپوشه‌ها؛ پیش‌فرض فعال است |
| `--no-recursive` | فقط فایل‌های مستقیم فولدر |
| `--extensions` | پسوندهای مجاز، پیش‌فرض `.md .markdown` |
| `--keep-html` | نگه‌داشتن فایل HTML میانی |
| `--fail-fast` | توقف با اولین خطا |
| `--verbose` | چاپ اطلاعات بیشتر |

### فونت و CSS

| گزینه | توضیح |
|---|---|
| `--font-family` | تنظیم خانواده فونت (CSS برای PDF، نام فونت برای DOCX) |
| `--font-file` | معرفی فایل فونت محلی (`.ttf`)؛ override روی `--font-dir` |
| `--font-dir` | فولدر حاوی `Vazirmatn-*.ttf` |
| `--css` | افزودن CSS سفارشی پس از CSS پیش‌فرض |

### صفحه (PDF)

| گزینه | توضیح |
|---|---|
| `--page-format` | اندازه صفحه مانند `A4`، `Letter`، `Legal` |
| `--margin` | حاشیه، مثل `12mm` یا `0.5in` |
| `--landscape` | خروجی افقی |

### Mermaid

| گزینه | توضیح |
|---|---|
| `--mermaid-js` | مسیر محلی فایل `mermaid.min.js` |
| `--mermaid-url` | URL آنلاین (override) |
| `--mermaid-theme` | `default`, `base`, `dark`, `forest`, `neutral`, `null` |
| `--mermaid-timeout` | timeout رندر هر دیاگرام به میلی‌ثانیه (پیش‌فرض `30000`) |
| `--ignore-mermaid-errors` | ادامه تبدیل حتی در صورت خطای Mermaid |

### DOCX

| گزینه | توضیح | پیش‌فرض |
|---|---|---|
| `--docx-image-scale` | ضریب کیفیت تصویر Mermaid (۱..۴) | `3` |
| `--docx-image-min-width` | حداقل عرض تصویر در سند (اینچ) | `4.0` |
| `--docx-image-max-width` | حداکثر عرض تصویر در سند (اینچ) | `6.5` |
| `--docx-font-size` | اندازه فونت متن (پوینت) | `12` |

### آفلاین

| گزینه | توضیح |
|---|---|
| `--browsers-path` | فولدر مرورگرهای Playwright |

### بسته‌بندی RTL

| گزینه | توضیح |
|---|---|
| `--wrap-rtl` | فعال‌سازی حالت بسته‌بندی Markdown با `<div dir="rtl">` |
| `--wrap-rtl-suffix` | پسوند فایل خروجی، پیش‌فرض `.rtl`. مقدار خالی برای overwrite |

## نمونه کامل PDF

```powershell
fa-md-pdf .\docs `
  -o .\pdf `
  --font-family "Vazirmatn, Tahoma, Segoe UI, Arial, sans-serif" `
  --page-format A4 `
  --margin 15mm `
  --mermaid-theme neutral `
  --keep-html
```

## نمونه کامل DOCX

```powershell
fa-md-pdf .\docs `
  -f docx `
  -o .\docx-output `
  --font-family "Vazirmatn" `
  --docx-font-size 12 `
  --docx-image-scale 3 `
  --docx-image-max-width 6.5
```
